# 新闻 Agent

## 定位与作用

新闻 Agent 负责检索与候选名称或代码直接相关的当日标题，并以保守方式归类正向和风险关键词。无直接证据时保持中性，不根据市场级新闻推断个股利好。

## 实现位置

- `scripts/lib/forecast-swarm/agents/news-agent.mjs`
- 入口函数：`runNewsAgent({ stock, news })`

## 输入

- `stock.name`、`stock.code`。
- `news[]`：预测时已经抓取的标题、来源和分类。

## 输出

- 直接关联标题数量。
- 正向与风险关键词数量。
- 最多若干条标题证据。
- 无直接证据和“标题不等于事件影响”的警告。

## 当前实现方法

> 参数证据等级：**E1 人工工程先验**。关键词及加减分均为人工设定，没有训练情绪分类器，详见 [参数来源与证据等级](parameter-provenance.md#新闻-agent)。

只有标题包含股票名称或代码才视为直接关联。设正向关键词条数为 $p$，风险关键词条数为 $n$：

$$
N=\operatorname{clamp}(50+12p-15n,0,100)
$$

无直接标题时固定为 50。置信度无直接证据时为 0.25；有直接证据时从 0.58 起随条数增加，最高 0.82。

## 当前风险与局限

1. 关键词方法无法理解否定、引用、传闻、预期差和上下文。
2. 股票简称可能与普通词重名，代码也可能出现误匹配。
3. 同一事件被多家转载会重复计数。
4. 标题发布时间、公告发布时间和预测截止时间尚未精确到分钟。
5. 未读取公告全文，无法判断事件规模、持续性和是否已被市场定价。
6. 新闻来源可信度目前未进入评分。

## 可深入优化方向

- 建立事件去重、实体链接和来源可信度评级。
- 读取交易所公告全文并保存原始链接及发布时间。
- 增加否定识别、事件类型、影响周期和新颖度。
- 引入受约束的语言模型做结构化抽取，但必须保存原文证据和模型版本。
- 评估新闻信号对不同持有周期的独立贡献。

## 不可突破的约束

- 只能使用预测截止时间前已发布且已抓取的资讯。
- 无直接证据必须保持中性，不能臆测。
- 新闻 Agent 不应单独成为买入理由，也不能改写正式排名。
