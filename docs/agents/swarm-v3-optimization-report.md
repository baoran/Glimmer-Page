# Agent Swarm 历史参数优化报告（v3 候选）

## 1. 报告摘要

本轮工作的目标不是再人工指定一组看起来更精确的参数，而是回答一个可检验的问题：**在历史日期可见数据、严格时间切分和冻结测试条件下，能否找到显著优于 Research-grounded Shadow Swarm v2 研究先验的仲裁参数？**

结论是：**没有。**

历史优化器给出的权重几乎回到研究先验，冻结测试中候选与基准的 AUC 都是 0.512，Brier 都是 0.251，Brier 改善为 0.0000。日期簇 bootstrap 的 AUC 95% 区间为 0.4532–0.5708，无法排除接近随机排序的可能。因此本轮候选被标记为 `E2-rejected`，不接入正式模型，也不接入新的前向 shadow。

这次实验的价值是形成了可复现的历史优化管线，并用冻结测试阻止了一次没有证据支持的参数更新。

## 2. 为什么进行本轮优化

v1 的精确权重属于 E1 人工工程先验；v2 根据动量、价值、流动性、波动风险和金融文本研究调整了方向，但精确权重仍属于 E1-R。

在本轮开始时，仓库自身还不具备直接训练条件：

- 正式 `horizon-vector-v2` 只有 2 个交易日、每周期 10 条记录，所有正式样本都尚未到期；
- 仓库中的 45 条已到期结果来自 `historical-replay-price-volume-v1`；
- 该回放使用当前高流动股票池反推历史，存在幸存者和样本选择偏差；
- 回放缺少历史时点 PE、市值和完整新闻，因此已明确标记 `trainingEligible: false`。

所以没有把仓库中现成的 45 条回放结果当成训练集，而是单独构建历史日期股票池和时间切分实验。

## 3. 优化对象

### 3.1 本轮实际优化的参数

本轮只优化 Swarm v2 **仲裁层**的以下内容：

1. 技术 Agent 权重；
2. 基本面 Agent 权重；
3. 市场 Agent 权重；
4. 风险 Agent 权重；
5. 历史评估使用的共识分概率映射中心和温度。

新闻历史覆盖不足，新闻 Agent 固定为中性 50，权重固定为 3%，没有使用缺失新闻拟合新闻参数。

### 3.2 本轮没有优化的内容

以下参数保持冻结：

- 数据 Agent 的完整性和一致性门控；
- 各专业 Agent 内部公式；
- 各 Agent 的置信度；
- 风险和数据硬质疑规则；
- v2 的支持 68、质疑 45 阈值；
- 正式 `horizon-vector-v2` 的六维权重、候选、分数和排名；
- v1、v2 已生成的任何历史日志。

因此，本报告验证的是“**现有 v2 Agent 输出如何加权**”，不是对整个选股模型的全面机器学习优化。

## 4. 参数口径

必须区分三组参数：

| Agent | v2 实际参数 | 历史优化基准 | v3 拟合候选 |
|---|---:|---:|---:|
| 技术 | 25.00% | 25.53% | 25.53% |
| 基本面 | 25.00% | 25.53% | 25.53% |
| 市场 | 15.00% | 15.32% | 15.30% |
| 新闻 | 5.00% | 3.00% | 3.00% |
| 风险 | 30.00% | 30.63% | 30.64% |

“历史优化基准”不是另一套人工观点。因为历史新闻缺失，本轮把新闻固定为 3%，再按 v2 原有比例将其余四个 Agent 归一化到 97%，所以 25%/25%/15%/30% 对应成为 25.53%/25.53%/15.32%/30.63%。

优化后的候选与该基准几乎完全相同。这说明现有样本没有提供足够证据让权重偏离研究先验。

## 5. 数据设计

### 5.1 数据来源

- 来源：BaoStock 0.9.3；
- 特征起点：2018-01-01；
- 最后一个候选锚点：2024-07-01；
- 后续结果数据截止：2025-12-31；
- 价格口径：不复权字段；收益使用后续每日 `pctChg` 复合计算；
- 六个周期：5、10、20、60、120、250 个市场交易日。

BaoStock 不是交易所官方 point-in-time 数据库，所以本轮只能称为“历史日期可见口径的时点化近似”，不能宣称已完全消除字段修订和退市覆盖偏差。

### 5.2 股票池构造

每个季度取第一个交易日，在该日期查询实际处于上市交易状态的 A 股股票：

- 排除 ST、退市、新股标记等不适合样本；
- 使用固定 SHA-256 哈希做确定性抽样；
- 每个季度最多抽取 320 只；
- 27 个季度锚点合计覆盖 458 只不同股票。

固定哈希抽样避免人为挑选，但它仍然只是完整 A 股横截面的子样本。

### 5.3 候选和观测

对每个季度锚点：

1. 只使用锚点当日及此前行情计算六维代理；
2. 复刻 `horizon-vector-v2` 的历史可用筛选和评分逻辑；
3. 每个周期保留前 20 个候选；
4. 用后续第 N 个市场交易日形成正负收益标签；
5. 剔除没有足够后续结果或明显异常的观测。

最终得到：

- 3,192 条候选—周期观测；
- 27 个季度日期簇；
- 458 只不同股票；
- 规范化输入 SHA-256：`efca719b9fae999f7e7c0fc35fa76225be852c01176021579135012cb3fc9201`。

## 6. 防止未来数据泄漏

本轮采用以下约束：

1. 股票是否上市交易按历史锚点日期查询；
2. 特征只读取锚点当日及此前的数据；
3. 标签只由锚点后的交易日形成；
4. 不使用当前股票快照选择历史样本；
5. 不使用当前新闻回填历史新闻；
6. 数据按时间而不是随机打乱切分；
7. 测试期不参与参数或正则强度选择；
8. 旧预测、旧 Agent 结果和正式排名均不回写。

## 7. 时间切分

| 数据段 | 日期 | 用途 | 样本数 |
|---|---|---|---:|
| 训练集 | 2018-01-01 至 2021-12-31 | 拟合参数 | 1,872 |
| 验证集 | 2022-01-01 至 2022-12-31 | 选择正则强度 | 480 |
| 冻结测试集 | 2023-01-01 至 2024-07-01 | 只做最终评价 | 840 |

冻结测试集没有参与权重优化或正则强度选择。

## 8. 优化方法

### 8.1 置信度收缩

先沿用 v2 的置信度收缩：

$$
X^*=50+c_X(X-50)
$$

其中 $X$ 是 Agent 原始分，$c_X$ 是证据置信度。低置信度 Agent 的分数会向中性 50 收缩。

### 8.2 共识分

历史优化共识为：

$$
C=w_TT^*+w_FF^*+w_MM^*+w_RR^*+0.03\times50
$$

约束为：

$$
w_T+w_F+w_M+w_R=0.97
$$

并且所有权重非负。每个可训练 Agent 相对研究基准最多移动 10 个百分点，防止有限样本把参数推到极端。

### 8.3 概率映射

为了使用 Brier 和 log loss 评价共识分，历史实验使用：

$$
p=\sigma\left(\frac{C-b}{\tau}\right)
$$

其中 $b$ 是中心，$\tau$ 是温度。最终历史拟合值为：

- $b=63.1057$；
- $\tau=20.0$。

这个 $p$ 只用于历史评估，不是经过长期前向校准的真实上涨概率。

### 8.4 目标函数与优化器

使用带 L2 正则的 log loss：

$$
\mathcal{L}=\operatorname{LogLoss}(y,p)+\lambda\lVert w-w_0\rVert_2^2
$$

- $w_0$ 为研究基准；
- $\lambda$ 候选为 1、5、20、80；
- 使用训练集拟合；
- 使用验证集 Brier 选择 $\lambda$；
- 最终选择 $\lambda=80$；
- 数值优化使用带约束的 SLSQP。

较强正则最终胜出，也说明数据更支持“不要明显偏离先验”，而不是大幅改权重。

## 9. 评价指标

- **AUC**：衡量正收益和非正收益的排序能力，0.5 接近随机；
- **Brier**：概率误差平方均值，越低越好；
- **Log loss**：概率预测对错误且自信结论的惩罚，越低越好；
- **正收益率**：样本中后续收益严格大于 0 的比例；
- **日期簇 bootstrap**：按日期整体重采样，降低同日股票和跨周期相关性造成的虚假精度。

预设的前向 shadow 接入门槛为：

1. 候选测试 Brier 必须优于研究基准；
2. 测试 AUC 至少 0.52；
3. 日期簇 bootstrap AUC 95% 区间下界至少 0.48。

## 10. 总体结果

| 模型 | 测试样本 | 正收益率 | AUC | Brier | Log loss |
|---|---:|---:|---:|---:|---:|
| 历史优化基准 | 840 | 44.52% | 0.512 | 0.251 | 0.695 |
| v3 拟合候选 | 840 | 44.52% | 0.512 | 0.251 | 0.695 |
| 常数概率基线 | 840 | 44.52% | — | 0.247 | — |

关键结果：

- 候选相对基准的 Brier 改善：**0.0000**；
- 候选 AUC：**0.5117**；
- 候选 Brier：**0.2508**；
- 常数概率 Brier：**0.2470**；
- 日期簇 bootstrap AUC 95% 区间：**0.4532–0.5708**；
- 日期簇 bootstrap Brier 95% 区间：**0.2466–0.2544**。

候选不仅没有优于研究基准，其 Brier 也没有优于测试集常数概率基线。因此没有证据把它描述成更可靠参数。

## 11. 分周期结果

| 周期 | 测试样本 | 正收益率 | AUC | Brier | 判断 |
|---|---:|---:|---:|---:|---|
| 一周 | 140 | 42.14% | 0.527 | 0.251 | 接近随机，证据不足 |
| 两周 | 140 | 45.00% | 0.594 | 0.246 | 有弱信号，需要更多日期验证 |
| 一个月 | 140 | 47.14% | 0.636 | 0.243 | 本轮最好，但样本和日期簇仍少 |
| 三个月 | 140 | 40.00% | 0.509 | 0.253 | 接近随机 |
| 六个月 | 140 | 42.86% | 0.392 | 0.257 | 方向不稳定 |
| 一年 | 140 | 50.00% | 0.417 | 0.255 | 方向不稳定 |

两周和一个月存在进一步研究价值，但不能只挑选表现较好的周期上线。这样会引入多重试验和事后选择偏差。需要预先登记新假设，再使用新的时间区间复验。

## 12. 为什么优化后几乎没变

主要原因包括：

1. v2 的多个 Agent 仍由相同六维 Vector 派生，Agent 之间高度相关；
2. 只有季度锚点，独立日期簇数量远少于 3,192 条表面观测数；
3. 新闻缺失，不能估计新闻的增量价值；
4. 基本面只有 PE 和流动市值代理，缺少公告时点财务数据；
5. 长周期只有单日截面代理，和真实长期因子定义不一致；
6. 训练集与验证集本身 AUC 低于 0.5，说明关系跨市场阶段不稳定；
7. 强正则抑制了有限样本产生的极端权重。

因此，“权重几乎不变”不是优化器失效，而是当前数据对参数变化投了否决票。

## 13. 决策

本轮状态：

- `evidenceLevel: E1-R`；
- `calibrationStage: E2-rejected`；
- `validated: false`；
- `shadowOnly: true`；
- `trainingEligible: false`；
- `recommendedForForwardShadow: false`。

执行决定：

1. 不修改 v2 实现参数；
2. 不创建在线 v3 shadow；
3. 不修改正式 Vector；
4. 不回填历史预测；
5. 保存脚本、输入哈希、结构化结果和失败报告；
6. 将本轮结果作为以后改进数据和模型结构的基线。

## 14. 风险与限制

1. BaoStock 不是官方 point-in-time 数据库，历史字段可能存在修订；
2. 每季度只抽取 320 只股票，不是完整横截面；
3. 总市值由成交量和换手率推导，是流通市值代理；
4. 没有历史公告时点财报、行业中性化和完整中文新闻；
5. 尚未考虑印花税、佣金、冲击成本和涨跌停成交约束；
6. 候选只来自模型高分区域，结论不能外推到全部 A 股；
7. 股票、日期和周期存在聚类相关性；
8. 分周期结果涉及多重比较，不能只选择表现最好的一个；
9. 概率映射没有经过正式前向可靠性校准。

## 15. 下一轮建议

若要得到真正可能通过 E2/E3 的参数，优先级应为：

1. 将历史锚点从季度提高到月度或周度，扩大独立日期簇；
2. 保存完整 point-in-time 全市场快照，而不是依赖后验接口；
3. 引入按公告日期可见的盈利、账面价值、现金流和投资因子；
4. 使用复权价格、停牌和退市处理，并加入交易成本；
5. 构建独立市场状态序列，避免市场 Agent 复用正式 `context`；
6. 建立中文金融文本数据集后再训练新闻 Agent；
7. 对两周和一个月弱信号预先登记假设，用全新的年份复验；
8. 使用滚动训练—验证—测试，而不是只做一次固定切分；
9. 达到历史门槛后仍先创建新版本 shadow，积累正式前向样本再考虑升级。
