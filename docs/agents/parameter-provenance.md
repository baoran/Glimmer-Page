# Agent Swarm 参数来源与证据等级

## 结论先行

当前 `forecast-supervision-swarm-v1` 的公式、权重、阈值和置信度均属于**第一版人工工程启发式（engineering priors）**：

- 不是来自某篇论文或行业标准；
- 不是从 Glimmer 历史样本拟合得到；
- 不是大模型自动学习的结果；
- 没有经过足够的样本外统计验证；
- 不应解释为上涨概率、最优权重或因果关系。

这些参数的用途是让第一版监督流程可运行、可解释、可审计，并为后续逐 Agent 优化建立基线。任何实质调整都必须升级版本，不能改写历史监督结果。

## 参数证据等级

项目对参数采用以下证据等级：

| 等级 | 含义 | 当前状态 |
|---|---|---|
| E0 | 临时示例，没有进入实现 | 不应进入生产 |
| E1 | 人工工程先验，有明确意图但未经统计验证 | 当前大多数 Swarm 参数 |
| E2 | 在历史训练样本中有统计支持 | 当前没有 |
| E3 | 滚动样本外验证有效，且考虑交易成本和多重检验 | 当前没有 |
| E4 | 长期正式前向样本稳定有效 | 当前没有 |

当前 Swarm 总体为 **E1**。页面展示的 `confidence` 也是规则设定的“证据充分度提示”，不是经过校准的概率。

在此基线上，项目新增了 [Research-grounded Shadow Swarm v2](research-grounded-v2.md)，证据标记为 **E1-R**：参数方向有论文和 A 股研究支撑，但精确权重与阈值仍未经 Glimmer 的 point-in-time 样本外验证。它只对未来新交易日并行记录，不覆盖 v1。

## 各 Agent 参数来源

### 数据 Agent

当前公式：

$$
D=0.70\times 100c+0.30q
$$

其中 $c$ 是必需字段完整率，$q$ 是来源状态分：`live=100`、`partial=72`、其他状态 `35`。

来源与意图：

- `70/30` 是人工设定，意图是让字段完整性占主导、来源状态作为次要修正。
- `100/72/35` 是人为构造的三档质量刻度，不来自数据源 SLA 或误差统计。
- `live` 置信度 0.96、其他 0.68 也是人工提示值。

证据等级：**E1**。

### 技术 Agent

当前公式：

$$
T=0.40M+0.35P+0.25S
$$

其中 $M$ 为价格动能、$P$ 为交易参与、$S$ 为波动稳定。

来源与意图：

- `40/35/25` 是基于“短期价格行为中动能和参与度通常比稳定性更直接”的人工排序。
- 它没有按一周至一年六个周期分别拟合。
- 涨幅 6% 和量比 3.5 的警告阈值是经验性风险线，不是统计最优分割点。
- 固定置信度 0.84 是人工设定。

证据等级：**E1**。并且三个输入来自正式 Vector，和原模型高度相关，不是独立证据。

### 基本面 Agent

当前公式：

$$
F=0.70V+0.30L
$$

其中 $V$ 为估值约束，$L$ 为流动性/规模代理。

来源与意图：

- 由于当前只有 PE、市值和流动性代理，人工让估值占 70%。
- 流动性不是公司基本面质量，只是数据不足时的规模承载代理。
- PE 60 倍警告是宽泛经验阈值，未按行业区分。
- 置信度 0.46 是主动压低的人工值，用来提示数据严重不足。

证据等级：**E1**，且应视为临时代理，而不是完整基本面模型。

### 市场 Agent

当前公式：

$$
M=V_{context}
$$

来源与意图：

- 直接复用正式 Vector 的 `context`，没有新增独立市场模型。
- 情境分 45 以下触发警告，沿用通用支持/质疑分区的思路。
- 置信度 0.78 是人工设定。

证据等级：**E1**。该 Agent 当前更接近“解释器”，不是独立研究信号。

### 新闻 Agent

当前公式：

$$
N=\operatorname{clamp}(50+12p-15n,0,100)
$$

其中 $p$ 为正向关键词标题数，$n$ 为风险关键词标题数。

来源与意图：

- 基线 50 表示没有直接证据时保持中性。
- `+12/-15` 是人工设定，并故意让风险词扣分略大于正向词加分，以保持保守。
- 正负关键词表由常见财经标题词人工整理，没有训练分类器。
- 置信度 0.25、0.58 起步和 0.82 上限均为人工证据充分度刻度。

证据等级：**E1**。标题重复、否定语义和误匹配会显著影响结果。

### 风险 Agent

当前方法：安全余量从 88 开始，按过热、量比、估值、振幅和小市值规则扣分。

来源与意图：

- 初始值 88 是为了给常规候选保留一定安全余量，同时避免默认满分。
- 涨幅 6%、量比 3.5、PE 60、振幅 7%、市值 100 亿元均为人工风险线。
- 每项扣分速度和上限也是人为控制，用来防止单一指标无限主导。
- 支持阈值 70、质疑阈值 50 比普通 Agent 更严格，体现风险审查职责。

证据等级：**E1**。当前没有证明这些阈值能最有效识别后续回撤或失败样本。

### 仲裁 Agent

当前公式：

$$
C=0.15D+0.25T+0.15F+0.15M+0.10N+0.20R
$$

其中 $R$ 是安全余量。

来源与意图：

- 技术 25%：第一版认为价格行为与当前数据覆盖最直接。
- 风险 20%：提高反方审查的重要性。
- 数据、基本面、市场各 15%：保持平衡。
- 新闻 10%：因当前只有标题级信息，主动降低权重。
- 共识 65 为支持、48 以下为质疑，是人工分区。
- 数据或风险 Agent 质疑时触发硬质疑，是治理规则，不是统计结论。
- 分差 20/35 对应中/高分歧，也是人工告警阈值。

证据等级：**E1**。

## 与正式六维 Vector 的关系

正式 `horizon-vector-v2` 本身的各周期基础权重和因子映射同样主要是人工规则，不是经过机器学习拟合的参数。例如短周期更重动能和交易参与，长周期更重估值、流动性和稳定性，这是合理的研究假设，但还不是被数据证明的事实。

正式模型目前唯一会根据结果变化的部分，是满足门槛后的有界经验校准：

$$
a_d=\operatorname{clamp}\left(0.08\times(WR_{high,d}-WR_{all}),-0.03,0.03\right)
$$

它要求每周期至少 20 个已到期样本、该维度至少 5 个高分样本，并把单维调整限制在 $\pm3\%$。其中 20、5、0.08 和 3% 也属于保守的人工治理参数，而不是统计最优值。

## 当前结果暴露出的校准问题

首日 30 个 Swarm 候选全部被仲裁为支持，同时 30 个都被标记为高分歧。这说明系统虽然可运行，但参数分布尚不理想：

1. 正式候选本来就是 Vector 高分样本，复用 Vector 的 Agent 容易普遍支持。
2. 新闻无直接证据时固定 50，而其他 Agent 常为高分，容易系统性制造高分歧。
3. 人工置信度和仲裁阈值尚未做可靠性校准。
4. 不能据此声称 Swarm 已提升预测准确率。

因此当前正确定位是“结构化审查基线”，不是“已经优化完成的智能投委会”。

## 参数如何科学升级

### 1. 先冻结版本

保留 `forecast-supervision-swarm-v1` 的历史输出，不追溯修改。新公式使用新的 Agent 版本；输出契约变化时升级 Swarm schema。

### 2. 明确优化目标

不同 Agent 使用不同目标，而不是统一追求上涨胜率：

- 数据 Agent：异常数据召回率、误报率、跨源偏差。
- 技术/基本面/市场/新闻 Agent：在控制其他因素后的增量预测能力。
- 风险 Agent：失败样本、下行波动和大回撤的召回率。
- 仲裁 Agent：校准、分层收益、风险调整结果和结论覆盖分布。

### 3. 使用 point-in-time 数据

所有特征必须按预测时实际可见时间保存。财报按公告日期，新闻按发布时间，行情按有效收盘；禁止使用后续修订数据回填。

### 4. 使用滚动样本外验证

按时间切分训练、验证和测试，不能随机打乱。参数只能在过去窗口估计，再用于后续未见日期。

### 5. 控制样本量和复杂度

当前每个交易日只有 30 个正式候选，且跨周期和跨股票存在相关性。样本不足时保持规则冻结，不因短期结果频繁调参。

### 6. 与基线比较

必须同时比较：

- 仅正式 Vector；
- Vector + 单个 Agent；
- Vector + 完整 Swarm；
- 简单等权或固定候选基线。

只有持续样本外优于基线，才允许提升证据等级。

### 7. 采用 shadow version

新参数先作为影子版本并行记录，不影响正式展示和经验池。积累足够到期结果后再决定是否升级。

## 修改参数时必须记录

每次变更应在文档和提交中记录：

- 原参数和新参数；
- 变更假设；
- 使用的数据区间和样本量；
- 是否 point-in-time；
- 训练、验证、测试切分；
- 评价指标和基线；
- 失败案例；
- 新 Agent/Swarm 版本；
- 回滚条件。
