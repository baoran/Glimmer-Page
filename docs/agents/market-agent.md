# 市场 Agent

## 定位与作用

市场 Agent 判断候选所处的整体市场环境是否顺风，重点观察核心指数广度和正式 Vector 中的情境修正分。它回答“当前市场是否支持承担这个候选的方向性风险”，而不是判断公司本身质量。

## 实现位置

- `scripts/lib/forecast-swarm/agents/market-agent.mjs`
- 入口函数：`runMarketAgent({ market, vector })`

## 输入

- `market.indices[]`：核心指数名称及预测日涨跌幅。
- `vector.context`：指数广度、市场强弱和个股过热惩罚形成的情境分。

## 输出

- 市场情境分。
- 上涨核心指数数量。
- 各核心指数涨跌证据。
- 情境分低于 45 时的逆风警告。

## 当前实现方法

> 参数证据等级：**E1 人工工程先验**。当前直接复用正式 `context`，并非独立拟合的市场模型，详见 [参数来源与证据等级](parameter-provenance.md#市场-agent)。

市场 Agent 分数直接采用：

$$
M=V_{context}
$$

固定置信度为 0.78。支持阈值为 65，质疑阈值为 45。

## 当前风险与局限

1. 与正式 `context` 完全同源，独立性较弱。
2. 核心指数等权广度不能反映全市场个股涨跌家数和成交结构。
3. 没有使用候选所属行业与指数之间的匹配关系。
4. `context` 同时包含个股过热惩罚，市场与个股风险存在混合。
5. 单日指数变化不能识别持续的风险偏好和市场 regime。

## 可深入优化方向

- 增加全市场上涨家数、涨停跌停、成交额和大小盘分化。
- 增加候选行业相对强度与行业扩散度。
- 建立牛市、震荡、风险收缩等市场状态识别。
- 将市场状态和六个持有周期关联。
- 拆分纯市场环境与个股过热，减少和风险 Agent 重复。

## 不可突破的约束

- 市场状态只能用预测日及以前的数据识别。
- 不得使用事后定义的行情阶段标签回写历史结论。
- 市场逆风只能提示，不得事后删除候选。
