# 基本面 Agent

## 定位与作用

基本面 Agent 检查候选的估值和规模约束。目前它只能称为“基本面代理 Agent”，因为数据快照尚未包含完整利润表、资产负债表和现金流量表。

## 实现位置

- `scripts/lib/forecast-swarm/agents/fundamental-agent.mjs`
- 入口函数：`runFundamentalAgent({ stock, vector })`

## 输入

- `stock.pe`：预测日市盈率。
- `stock.marketCap`：预测日总市值。
- `vector.valuation`：正式模型估值约束分。
- `vector.liquidity`：规模及成交承载代理分。

## 输出

- 估值约束和规模流动性信号。
- 缺少盈利增长、负债和现金流的固定警告。
- 市盈率超过 60 倍的估值风险警告。
- 市盈率和总市值证据。

## 当前实现方法

> 参数证据等级：**E1 人工工程先验**。当前只是数据不足条件下的代理公式，详见 [参数来源与证据等级](parameter-provenance.md#基本面-agent)。

$$
F=0.70V+0.30L
$$

其中 $V$ 为估值约束，$L$ 为流动性代理。由于基本面证据明显不足，置信度固定为 0.46。支持阈值为 65，质疑阈值为 45。

## 当前风险与局限

1. 单一 PE 无法覆盖亏损企业、周期股、金融股和高增长公司。
2. 流动性与公司质量不是同一概念，当前只是规模承载代理。
3. 缺少收入增长、利润增长、ROE、现金流、负债率和盈利质量。
4. 未做行业内估值比较，跨行业 PE 不可直接等价。
5. 财务数据可能存在报告期滞后，必须按公告可见时间处理。

## 可深入优化方向

- 建立带公告时间戳的 point-in-time 财务快照。
- 加入行业分位数、PE/PB/PS、ROE、自由现金流和负债结构。
- 为周期行业、金融行业和亏损企业定义不同估值方法。
- 将数据覆盖率映射到动态置信度。
- 评估基本面信号在 60/120/250 日周期中的增量效果。

## 不可突破的约束

- 财报只能从实际披露日之后使用，不能按报告期末提前使用。
- 不得用当前财报回填历史预测。
- 完整财务模型上线时必须升级 Agent 和模型版本。
