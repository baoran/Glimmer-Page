# 数据 Agent

## 定位与作用

数据 Agent 是 Swarm 的输入守门员。它判断当前候选的行情字段是否完整、核心数据源是否处于可接受状态，并为仲裁 Agent 提供数据可信度信号。它不验证股票是否值得入选，也不负责修复或补全数据。

## 实现位置

- `scripts/lib/forecast-swarm/agents/data-agent.mjs`
- 入口函数：`runDataAgent({ stock, sourceStatus })`

## 输入

- `stock`：必须包含 `price`、`change`、`turnoverRate`、`volumeRatio`、`pe`、`marketCap`、`turnover`、`high`、`low`、`previousClose`。
- `sourceStatus`：`live`、`partial` 或 `stale`。

输入只能来自预测日当时保存的行情截面。

## 输出

遵循统一专业 Agent 契约，重点包括：

- 字段有效数量。
- 来源状态。
- 观察价、成交额和总市值证据。
- 非实时来源警告。

## 当前实现方法

设字段完整率为 $c$，来源得分为 $q$：

- `live`：$q=100$
- `partial`：$q=72$
- 其他状态：$q=35$

数据质量分为：

$$
D=0.70\times 100c+0.30q
$$

`live` 时置信度为 0.96，其他状态为 0.68。普通结论阈值为：支持不低于 65，质疑低于 45。

## 当前风险与局限

1. `Number.isFinite` 只能判断格式，不能发现数值虽合法但实际错误。
2. `sourceStatus` 是粗粒度状态，不能反映每个字段的具体来源和时间戳。
3. 尚未交叉比较东方财富、腾讯、新浪之间的价格偏差。
4. 未检测高低价关系、负成交额、异常市值等业务一致性。
5. 字段完整不等于数据新鲜；当前没有逐字段 freshness 检查。

## 可深入优化方向

- 为每个字段保存来源、抓取时间和原始值。
- 增加跨源价格偏差、成交额偏差和时间戳一致性检查。
- 增加 OHLC 业务约束和异常值检测。
- 根据不同字段的重要性使用加权完整率。
- 将数据异常分成可降级与必须阻断两类。

## 不可突破的约束

- 不能用最新数据修正历史预测日快照。
- 不能自行把缺失字段填成乐观值。
- 数据 Agent 的质疑只触发监督提示，不能删除已生成候选。
