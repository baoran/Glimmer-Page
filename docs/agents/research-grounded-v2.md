# Research-grounded Shadow Swarm v2

## 状态

- 版本：`forecast-supervision-swarm-research-v2`
- 参数证据：**E1-R，文献支撑的工程先验**
- `validated: false`
- `shadowOnly: true`
- `trainingEligible: false`
- 启用方式：只对启用后的新交易日预测并行记录；不回填旧日志

这是一版基于论文、A 股研究和风险治理经验改进的参数先验，不是已经在 Glimmer 数据中拟合出的最优模型。文献支持的是因子方向和治理原则，精确权重、阈值和适用期仍需正式前向样本与滚动样本外验证。

## 研究依据

### 动量与成交量

- Jegadeesh 与 Titman（1993）记录了过去赢家与输家在 3–12 个月持有期的动量现象。DOI：[10.1111/j.1540-6261.1993.tb04702.x](https://doi.org/10.1111/j.1540-6261.1993.tb04702.x)。
- Naughton、Truong 与 Veeraraghavan（2008）研究了中国股票市场的动量策略，并把成交量纳入分析。DOI：[10.1016/j.pacfin.2007.10.001](https://doi.org/10.1016/j.pacfin.2007.10.001)。
- Lee 与 Swaminathan（2000）讨论价格动量和交易量关系。DOI：[10.1111/0022-1082.00280](https://doi.org/10.1111/0022-1082.00280)。

对实现的影响：保留动量，但降低交易参与的直接正向权重；当前只有单日代理而不是论文使用的连续历史，所以技术 Agent 的置信度显著降低，并随持有期变长继续下降。

### 中国市场的价值与规模

- Liu、Stambaugh 与 Yuan（2019）专门研究中国市场的规模和价值。DOI：[10.1016/j.jfineco.2019.03.008](https://doi.org/10.1016/j.jfineco.2019.03.008)。

对实现的影响：基本面 Agent 把当前有限输入更多集中于估值代理，但由于缺少论文中更完整的价值构造、账面价值和壳价值处理，置信度仍然很低；并未把“价值有效”错误转换为“PE 越低越一定上涨”。

### 流动性与波动风险

- Amihud（2002）研究非流动性与股票收益的横截面和时间序列关系。DOI：[10.1016/S1386-4181(01)00024-6](https://doi.org/10.1016/S1386-4181(01)00024-6)。
- Ang、Hodrick、Xing 与 Zhang（2006）发现高特质波动股票平均收益较低。DOI：[10.1111/j.1540-6261.2006.00836.x](https://doi.org/10.1111/j.1540-6261.2006.00836.x)。

对实现的影响：风险 Agent 在仲裁中权重最高；更早开始对高振幅和较弱成交承载进行连续折扣，而不是只在非常极端时告警。但日内振幅不是论文中的特质波动，成交额也不是完整 Amihud 指标，因此仍属于代理实现。

### 新闻与金融文本

- Tetlock（2007）发现媒体悲观与短期下行压力及随后反转相关，强调媒体内容可能反映噪声和流动性交易，而非纯粹基本面信息。DOI：[10.1111/j.1540-6261.2007.01232.x](https://doi.org/10.1111/j.1540-6261.2007.01232.x)。
- Loughran 与 McDonald（2011）表明通用词典会在金融文本中产生大量误分类，需要金融领域词典。DOI：[10.1111/j.1540-6261.2010.01625.x](https://doi.org/10.1111/j.1540-6261.2010.01625.x)。

对实现的影响：新闻权重从 10% 降至 5%；无直接标题时置信度为 0；去重标题；风险词扣分是正向词加分的两倍。由于中文关键词尚未经过金融语料校准，新闻 Agent 仍不能成为主要结论来源。

## v2 参数

### 专业 Agent

#### 数据 Agent

$$
D=0.60C+0.25Q+0.15B
$$

- $C$：字段完整率。
- $Q$：来源质量，`live=100`、`partial=60`、其他为 0。
- $B$：价格、OHLC、成交额和市值的业务一致性。
- 支持阈值 80，质疑阈值 60。
- 若收盘观察价不在最高/最低价之间、最高价低于最低价，质量分硬性封顶 55；`stale` 来源硬性封顶 40，防止完整字段掩盖致命一致性问题。

数据质量不进入收益共识分，只作为治理门控。理由是数据完整性不是上涨因子。

#### 技术 Agent

$$
T=0.45M+0.20P+0.35S
$$

- 动量 $M$ 45%。
- 交易参与 $P$ 20%。
- 稳定性 $S$ 35%。
- 置信度：5/10 日周期 0.62，20 日周期 0.52，60/120/250 日周期 0.38。

相比 v1，参与度降权、稳定性升权，并且不再把单日技术截面对长周期赋予高置信度。

#### 基本面 Agent

$$
F=0.85V+0.15L
$$

- 估值代理 $V$ 85%。
- 规模/流动性代理 $L$ 15%。
- 短周期置信度 0.32，60 日及以上为 0.48。

基本面信号理论上更适合较长周期，但目前输入只有 PE 和规模代理，因此不能给予高置信度。

#### 市场 Agent

$$
MKT=V_{context}
$$

置信度从 v1 的 0.78 降至 0.55，因为它仍复用正式 `context`，没有提供独立市场状态模型。

#### 新闻 Agent

去重直接标题后：

$$
N=\operatorname{clamp}(50+6p-12n,0,100)
$$

- 无直接标题时 $N=50$ 且置信度为 0。
- 正向词每条加 6，风险词每条减 12。
- 有证据时置信度从 0.38 起，最高 0.60。

#### 风险 Agent

安全余量从 80 开始，使用连续折扣：

- 振幅超过 4%：每增加 1 个百分点扣 4，最多扣 25。
- 涨幅超过 5%：每增加 1 个百分点扣 4，最多扣 15。
- 量比超过 3：每增加 1 扣 4，最多扣 10。
- PE 超过 50：每增加 1 倍扣 0.25，最多扣 12。
- 市值低于 100 亿元：扣 10。
- 成交额低于 3 亿元：按缺口比例最多扣 8。

支持阈值 68，质疑阈值 45，置信度 0.78。

这些阈值没有直接来自论文，而是把论文支持的“波动和流动性值得更高风险权重”转换成当前有限字段上的保守代理。因此仍是 E1-R，不是 E2。

## 置信度收缩

v1 直接聚合原始 Agent 分数，导致低置信度新闻和基本面代理也能明显影响共识。v2 先把每个分数向中性 50 收缩：

$$
X^*=50+c_X(X-50)
$$

其中 $c_X$ 是 Agent 的证据置信度。无证据的新闻 Agent 因 $c_N=0$，无论原始中性分如何，都只贡献 50。

## v2 仲裁

数据 Agent 仅作为质量门控，不进入收益共识。影子共识为：

$$
C_{v2}=0.25T^*+0.25F^*+0.15MKT^*+0.05N^*+0.30R^*
$$

- 风险 30%。
- 技术和基本面各 25%。
- 市场 15%。
- 新闻 5%。

规则：

- 数据或风险 Agent 质疑时，最终质疑。
- 否则共识不低于 68 才为支持，低于 45 为质疑，中间为中性。较高支持门槛体现“未验证 shadow 应优先保留中性”的治理原则，而不是用今日结果拟合阈值。
- 置信度调整后专业分差至少 30 为高分歧，至少 18 为中分歧。

## 为什么是 shadow，而不是替换 v1

1. 文献不能直接给出适合本站股票池和数据源的精确权重。
2. 当前只有单日截面、PE 代理和标题新闻，与论文变量并不完全相同。
3. 首日 v1 出现“30 个全部支持且全部高分歧”，说明需要比较，但不能用单日结果调参。
4. v2 必须积累新的正式前向到期样本，不能回填启用日前日志。
5. v2 不进入经验池，不影响正式六维 Vector，也不替换 v1。

## 升级到更高证据等级的条件

至少完成以下步骤才能从 E1-R 升级：

- 使用 point-in-time 数据；
- 按时间滚动的样本外验证；
- 分周期比较 v1、v2 和正式 Vector；
- 报告支持/中性/质疑分布、分歧率、胜率、均值、中位数和下行风险；
- 控制股票和日期聚类相关性；
- 检查多重试验和过拟合；
- 新版本先继续 shadow 运行，确认稳定后再决定是否提升地位。
