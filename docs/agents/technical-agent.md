# 技术 Agent

## 定位与作用

技术 Agent 复核正式候选的短中期价格行为是否得到动能、交易参与和波动稳定性的共同支持。它是监督解释，不是第二套独立选股器。

## 实现位置

- `scripts/lib/forecast-swarm/agents/technical-agent.mjs`
- 入口函数：`runTechnicalAgent({ stock, vector })`

## 输入

- `stock.change`：当日涨跌幅。
- `stock.volumeRatio`：量比。
- `stock.turnoverRate`：换手率。
- `vector.momentum`、`vector.participation`、`vector.stability`：预测时保存的正式 Vector 分量。

## 输出

- 三个技术维度的主要信号。
- 单日涨幅超过 6% 的过热警告。
- 量比超过 3.5 的持续性警告。
- 当日涨跌、量比和换手率证据。

## 当前实现方法

$$
T=0.40M+0.35P+0.25S
$$

其中 $M$ 为价格动能，$P$ 为交易参与，$S$ 为波动稳定。固定置信度为 0.84。支持阈值为 65，质疑阈值为 45。

## 当前风险与局限

1. 使用正式 Vector 的三个分量，与正式评分并非完全独立，可能形成重复确认。
2. 主要基于单日截面，缺少均线、趋势持续期、缺口、相对强弱和多周期波动。
3. 相同公式用于六个持有周期，尚未体现周期差异。
4. 固定置信度不能反映数据完整度和市场状态。
5. 高动量既可能延续也可能反转，简单阈值难以区分。

## 可深入优化方向

- 使用预测时可见的 5/20/60 日收益和成交量历史。
- 按六个持有周期配置独立技术信号和阈值。
- 增加行业相对强弱、指数相对强弱和波动调整动量。
- 用已到期样本做滚动样本外验证，但保持版本隔离。
- 分析技术 Agent 对正式 Vector 的增量信息，而不是只看相关性。

## 不可突破的约束

- 连续历史必须截止到预测日，不能包含后续 K 线。
- 不能根据在途浮盈亏调整参数。
- 技术结论不能改变正式 `score` 或 `rank`。
