# 风险 Agent

## 定位与作用

风险 Agent 是 Swarm 的反方审查者，主动寻找候选的过热、异常量能、高估值、高振幅和小市值风险。它输出的是“安全余量”而非“风险严重度”：分数越高表示触发的显式风险越少。

## 实现位置

- `scripts/lib/forecast-swarm/agents/risk-agent.mjs`
- 入口函数：`runRiskAgent({ stock, amplitude })`

## 输入

- `stock.change`、`stock.volumeRatio`、`stock.pe`、`stock.marketCap`。
- `amplitude`：预测日日内振幅。

## 输出

- 0–100 的安全余量分。
- 所有已触发风险中的最多三条警告。
- 振幅、涨跌幅和市盈率证据。

## 当前实现方法

> 参数证据等级：**E1 人工工程先验**。起始分、风险线和扣分幅度尚未由后续回撤数据校准，详见 [参数来源与证据等级](parameter-provenance.md#风险-agent)。

安全余量从 88 开始，按以下规则扣分：

- 涨幅高于 6%：每超 1 个百分点扣 6，最多扣 22。
- 量比高于 3.5：每超 1 扣 5，最多扣 15。
- PE 高于 60：每超 1 倍扣 0.3，最多扣 18。
- 振幅高于 7%：每超 1 个百分点扣 3，最多扣 20。
- 总市值低于 100 亿元：扣 12。

风险 Agent 使用更严格阈值：安全余量不低于 70 为支持，低于 50 为质疑。它和数据 Agent 的质疑会触发仲裁硬质疑。

## 当前风险与局限

1. 扣分是人工规则，尚未按周期和行业校准。
2. 风险之间相关，例如涨幅、振幅和量比可能重复惩罚同一事件。
3. 未覆盖停牌、减持、质押、诉讼、监管、财务造假和退市风险。
4. 未覆盖组合集中度、行业拥挤和相关性风险。
5. 安全余量高只表示未触发现有规则，不代表低风险。

## 可深入优化方向

- 分离市场风险、个股风险、事件风险和组合风险。
- 按行业、市值和持有周期建立分位数阈值。
- 加入公告事件、价格跳空、流动性冲击和尾部风险指标。
- 计算风险规则对真实回撤、下行波动和失败样本的召回率。
- 增加规则相关性分析，避免重复扣分。

## 不可突破的约束

- 风险 Agent 可以触发人工复核，但不能删除不可变预测。
- 不能根据未来最大回撤给预测日风险打分。
- 优化目标不能只追求胜率，还要检查漏报严重风险的比例。
