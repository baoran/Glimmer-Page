# Glimmer

个人 A 股收盘情报与前向验证页面。网站由原生 HTML、CSS 和 JavaScript 构建，数据通过 GitHub Actions 在每天收盘后自动更新并部署到 GitHub Pages。

## 多周期选股实验室

- 每个交易日为一周、两周、一个月、三个月、六个月和一年六个周期分别记录 5 只候选股票。
- `horizon-vector-v2` 使用价格动能、交易参与、流动性、估值约束、波动稳定和市场情境六维向量评分，并保存每只股票的选择依据与资讯核验快照。
- 预测日志只使用生成当时可见的收盘截面并保留因子快照，不用未来数据回填或修改历史入选结果。
- 每个后续交易日更新浮动收益和“市场、资讯、模型、明日经验”复盘，到达约定交易日数后记录到期价格、收益与胜负结果。
- 研究日历可按交易日回看候选、选择依据和当日报告；只有至少 20 个已到期样本才允许从下一交易日起温和校准权重。
- `node scripts/backfill-forecast-preview.mjs` 可生成前 10 个交易日的历史回放体验。回放使用真实未复权日线，但股票池取自当前高流动股票且历史估值缺失，因此与正式前向日志、胜率及经验池严格隔离。
- 运行 `node scripts/validate-forecast-data.mjs` 可检查六周期、每期五只、向量完整性和追踪引用一致性。

该模块是规则排序与前向观察实验，不构成收益承诺或投资建议。当前观察价使用预测日收盘价，并不代表次日真实可成交价格。
